# 寻物有声

面向校园场景的失物招领网页应用，帮助同学发布和查找失物信息。

## 主要功能

- 用户注册与登录
- 发布失物、招领信息
- 选择照片和裁剪照片
- 搜索、查看物品详情
- 提交认领信息或提供线索
- 更新物品处理状态

## 使用技术

- 前端：HTML、CSS、JavaScript
- 后端：Node.js、Express
- 数据库：SQLite

## 本地运行

1. 安装 Node.js 24。
2. 在项目根目录打开终端。
3. 执行 npm install 安装依赖。
4. 执行 npm start 启动服务。
5. 浏览器访问 http://127.0.0.1:3000/ 。
